# BindWitness v0.1.2

This patch release adds a reproducible Perl bundled/system zlib case study and
updates the public documentation. CLI behavior, provider contracts, exit codes
and schema version 1 remain unchanged from v0.1.1.

- Real Compress::Raw::Zlib 2.103 and 2.105 workloads demonstrate how global load
  order changes selected symbol providers and how upstream symbol prefixing
  isolates the bundled implementation. The case includes pinned source checksums,
  build provenance, full representative reports and offline replay instructions.
- The validation workload now stops when either mandatory library load fails.
  Eight regression scenarios cover both libraries, both versions and both load
  orders, preventing failed loading from appearing to be successful isolation.
- Native Bookworm AMD64 and ARM64 CI runs the case using the validated release
  binary. Build evidence is archived without changing upstream filenames;
  reports and configurations remain available separately.
- The README and documentation explain setup, contracts, evidence limitations,
  validation and release packaging without local development journals.

The release workflow validates AMD64 and ARM64 in Debian Bookworm (glibc 2.36)
and Trixie (glibc 2.41) before packaging the native Bookworm binaries. The Perl
case demonstrates selected observed bindings; it does not claim to reproduce
the upstream AlmaLinux failure or prove general ABI compatibility.

Download `bindwitness-0.1.2-linux-amd64.tar.gz` or
`bindwitness-0.1.2-linux-arm64.tar.gz` and `SHA256SUMS` from the release assets.
Verify the selected archive's checksum before extracting it. Each archive
contains the CLI, Apache-2.0 license, README, documentation and JSON schemas.
Workloads and source fixtures are available in the v0.1.2 source checkout.
